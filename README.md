# Joshu

AI-powered CLI assistant that converts natural language into shell commands.

## Install

### Quick Setup (Recommended)

**Windows (PowerShell):**
```powershell
git clone https://github.com/Faycalraghibi/Joshu.git joshu
cd joshu
.\clean_install.ps1
```

**Linux/macOS:**
```bash
git clone https://github.com/Faycalraghibi/Joshu.git joshu
cd joshu
chmod +x clean_install.sh
./clean_install.sh
```
